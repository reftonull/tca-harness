# Integrations

[isowords](isowords/README.md) demonstrates embedding the harness in an existing app's original root store, including real navigation and scored gameplay. Setup fetches the separately licensed upstream source into an ignored checkout.

[shelf](shelf/README.md) is a small reading-list app built to exercise every [testing pattern](../docs/testing.md) on all three rungs, with planted bugs (`SHELF_BUGS`) that each pattern catches.
