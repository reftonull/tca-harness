# Integrations

[shelf](shelf/README.md) is a small reading-list app built to exercise every [testing pattern](../docs/testing.md) on all three rungs, with planted bugs (`SHELF_BUGS`) that each pattern catches.

[criticalmaps](criticalmaps/README.md) integrates a production app with a live public service (Critical Maps, TCA 1.26): a read-only guard for recording fixtures from production, explicit descriptors over upstream modules, journeys on a Mac Catalyst headless host and the simulator, and the bugs exploration, chaos and the rung differential found.
